# Source code

- `network.py`, `simulator.py`, and `update_strategies.py`: continuous-attractor model.
- `visualisation.py`: simulation plots and reports.
- `reproduction_paths.py`: notebook input directories and environment overrides.
- `check_inputs.py`: checks for required files without loading data or running analyses.

Run the simulator with `../main_gain.py`. Its default output directory is
`data/continuous_attractor`, relative to the working directory. See the [README](../README.md).
