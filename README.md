# Neural mechanisms for resilient sensory computation under metabolic stress

Code accompanying the manuscript:

Castedo, S. H., Padamsey, Z., Rochefort, N. L. & Monasson, R. *Neural mechanisms for resilient sensory computation under metabolic stress.*

[Preprint](https://doi.org/10.64898/2026.10.29.761790)

This repository contains Python code for analysing neural population activity in mouse primary visual cortex under food restriction and control conditions, including noise covariance, population coding geometry and signal-to-noise ratios, as well as numerical simulations of a recurrent neural network model.

The repository is being prepared for reproducibility and peer review. Installation instructions, data availability and instructions for reproducing the main figures will be added as the code is organised.
